# Crypto Analysis Software 🚀

An asynchronous Python scanner built with Streamlit, CCXT, Pandas, and Asyncio that analyzes real-time crypto market data across KuCoin, MEXC, and OKX. It computes RSI momentum across 15m and 1h timeframes while tracking volume spikes to surface live high-conviction bullish and bearish signals on an interactive dashboard.

---

## 🌟 Key Features
- **Multi-Exchange Integration:** Fetches real-time ticker and candle data asynchronously from KuCoin, MEXC, and OKX using CCXT.
- **RSI Momentum Tracking:** Calculates RSI across multiple timeframes (15m and 1h).
- **Volume Spike Alerts:** Detects sudden volume surges relative to average trading volume.
- **Interactive UI:** Built using Streamlit for clean data rendering and simple navigation.
